# Akıl Zeka Sınıfı
1. GitHub'da yeni depo (repository) açın, bu klasörün İÇİNDEKİ her şeyi (.github klasörü dahil) yükleyin. Dal adı: main
2. Depoda **Actions** sekmesi → "APK Derle" çalışır (3-5 dk). Çalışmazsa "Run workflow" deyin.
3. Bittiğinde çalışmanın içinde **Artifacts → akil-zeka-apk** dosyasını indirin, zip'ten çıkan app-debug.apk'yı telefona/tablete kurun.
